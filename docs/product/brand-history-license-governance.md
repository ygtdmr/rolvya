# Brand evolution and asset provenance

## Why this record exists

The Rolvya naming and visual identity conversation contained several **successive preferences**. Preserving the full evolution is useful for later AI coding agents, but **earlier variants must not overwrite the last explicit owner-approved direction**. The current design status is described in [brand positioning](brand-positioning.md); the [decision register](../decisions/README.md) governs accepted product policy.

This reconstruction is based on **retrievable historical conversation excerpts and summaries**, not a line-by-line complete transcript. Artwork itself, an editable SVG master and a formal trademark clearance report were not available as verified repository files during this audit. Do not invent exact final HEX values or claim any logo vector file has been validated.

## Naming timeline and current rule

1. The user wanted a short, natural-sounding single-word technology identity and prioritized conflict checks on **GitHub and X**. Earlier proposals including **Dagyro** and **Velnqo** were rejected.
2. **Rolvya** was selected. It is a coined name with no established dictionary meaning, acronym expansion or direct linguistic claim about DAGs/agents.
3. Prior quick search observations are not a trademark or username/domain guarantee. Github/X account availability and commercial trademark conflicts **must not** be declared cleared from historical snapshots.
4. **Approved:** name **Rolvya** with normal capitalization; spelling **Rolvya** in official repository and user-facing copy. Do not rename or invent an expansion.

Some historical prompts asked for wordmark and avatar variants; these are **prompt requests**, not proof that every resulting variant was approved or exists in the source repository. The accepted symbol was described as geometric and suggestive of several agents/coordinated motion; do not derive exact geometry or SVG paths from those prose descriptions.

**Binding creative boundary:** navy/blue/gray; **no gold**; do not modify finalized logo absent explicit owner request. If the app needs an SVG/icon, obtain the **original approved asset** rather than create a lookalike and call it canonical. If the exact final palette is needed for CSS, resolve from the verified asset/owner—not from the superseded Midnight Brass swatches.

## Messaging and slogan

- Approved short description: **“Open-source orchestration for AI coding agents, with dependency-aware task planning and parallel execution.”**
- Approved tagline: **“One Plan. Many Agents.”**
- User requested the slogan not be repeated unnecessarily; in the repository README it should appear **once**, not in multiple decorative headings/footers.
- Communication must distinguish **planned capability**, **approved design**, **implemented code**, and **tested/verified release**. Brand positioning cannot promise a shipped system before it exists.

The full tagline is quoted here once for historical precision. That is not permission to duplicate it throughout product marketing.

## Current source license and brand rights

**Current approved source-code license: MIT** (SPDX: `MIT`), as published in [LICENSE](../../LICENSE). It permits commercial use, copying, modification, distribution and sublicensing subject to retaining the required notices. Source licensing does not automatically grant rights to project names, trademarks or separately protected logo assets.

No legal opinion or trademark registration is implied. Future organization transfer, dual licensing, contributor agreements, source attribution and brand/logo usage rules require separate legal review and explicit owner decisions.

The user also discussed proposed GitHub repository discovery topics such as `ai-agents`, `multi-agent`, `orchestration`, `coding-agents`, `developer-tools`, `open-source` and `DAG`. These are **historical suggested metadata**, not proof that all topics were actually configured on the repository. The repository About/topics require separate authorized settings changes and review.

## Anti-regression checks for AI agents

- A branding PR introducing gold/brass from an old prompt without new owner approval is rejected.
- A license document restricting commercial reuse, or omitting the MIT copyright and permission notice, is inconsistent with the approved project license.
- A speculative “Rolvya means …” etymology or guaranteed unique name conflicts with source evidence.
- A README update inserting the tagline in multiple sections is inconsistent with the writing preference.
- A new logo SVG drawn from text description cannot be labeled the final approved logo.
- A move to an organization, another license or protected brand governance requires explicit owner authorization.
